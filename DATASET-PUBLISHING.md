# Third-Party Dataset Publishing

The text preprocessing notebook was delivered together with an approximately 4 MB file named `json` containing scraped bibliographic/article information and abstracts. This full local copy is included for backup and has not been verified for redistribution rights. **The file is excluded from `git add .` by `.gitignore`** until you have checked permissions. The notebook expects the exact file `json` next to it. Other image/training datasets are not included when absent from the original submission.
